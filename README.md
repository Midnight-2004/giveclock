# GiveClock

轻量化进服给钟插件

## 插件作用

当玩家进入服务器时，给玩家一个钟。

玩家每次进入服务器时都会检测。

+ 如果玩家有钟，则不进行任何操作。

+ 如果玩家背包满了但是没有钟，则不给钟，需要玩家腾出背包空间后重新进入服务器才能获得钟。

钟的物品名称、第一行描述可进行自定义。

成功获得钟时的提示、背包满时的提示也可以进行自定义。

## 插件命令

+ `/giveclock reload` 重载插件配置

## 权限节点

+ `giveclock.giveclock` 允许获得钟表
    + 默认所有玩家均有权限
+ `giveclock.reload` 允许使用`/giveclock reload`命令
    + 默认为管理员权限
